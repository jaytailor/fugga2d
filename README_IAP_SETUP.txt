FUGGA - IN-APP PURCHASE SETUP
==============================================================================

Your IAP system is ready! Follow these simple steps:

STEP 1: OPEN UNITY EDITOR
--------------------------
Open your Fugga project in Unity Editor


STEP 2: ONE-CLICK SETUP
--------------------------
In Unity menu bar: Fugga → Setup IAP System
Click "Yes"
Done! IAPManager is added to your menu scene.


STEP 3: CREATE BUTTONS (OPTIONAL)
--------------------------
In Unity menu bar: Fugga → Create IAP Button
Repeat 3 times for 3 coin packages
Position buttons in your UI


STEP 4: GOOGLE PLAY CONSOLE
--------------------------
Go to: https://play.google.com/console
Select your app → Monetize → Products → In-app products
Create 3 products:

1. Product ID: com.jayt.fugga.coins500
   Name: 500 Premium Coins
   Price: $0.99

2. Product ID: com.jayt.fugga.coins1500
   Name: 1500 Premium Coins
   Price: $1.99

3. Product ID: com.jayt.fugga.coins3000
   Name: 3000 Premium Coins
   Price: $2.99

Save each product and wait 2-4 hours for activation.
